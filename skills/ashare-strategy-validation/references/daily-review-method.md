# 通用经验与定期复盘

成交事实和归因用[交易复盘](../../ashare-trade-review/SKILL.md)，事件、变体对照、基线与统计用[验证流程](validation-protocol.md)，日内分析用[日内框架](../../ashare-position-t/references/intraday-decision-framework.md)。

经验按观察、候选假设、相应验证记录；保留稳定身份、适用市场状态、证据日期和范围、反例、失效条件与下一验证。同义经验追加证据，新规则另立未来生效版本；单笔正负差不证明因果、通用阈值或稳定胜率。

先核当时版本是否实际评估、观察缺口与提醒时序，再讨论方向、空间与执行。最新报价不能抹掉等待期间；后来修订不能倒填。空间不能越过当时已知中间障碍，延后价格也可能更有利，不能把所有亏损归于延迟。

采样覆盖与分析覆盖分别核验。纸面计量协议、执行资格与结果分别记录：价区外的正毛差不能使执行资格合格，价区内的负毛差也不能全部归于首价越界。保留全部样本及合格、不合格、资格未知分组中的正负结果，不按成绩反选资格或删除反例。

发送前价区检查只能证明该检查时点，不能保证提醒后的协议首价仍合格；分别保留检查、发出、首个可核新报价及资格。检查价不能替换冻结协议首价，也不能改选后续有利报价。风险源、实际取得、评估、发出与首价分时钟核对，未知阶段保持UNKNOWN；观察到时差和不利价格变化，不足以将全部损失归于推理或通知延迟，无反事实不量化提速的因果贡献。

目标触及、实际获知、评估、发送与送达分时钟记录，目标不是成交。切源或缺口后，受影响窗口重建，未受影响的证据可继续研究。来源后续修订保留决策时实际取得版本并追加更正关系或敏感性分析，不回写旧决定；同一事件重复读取及修订不增加独立样本数。

新假设只用冻结协议生效后的未来样本验证，已看过的案例不能再称未触碰样本外；费用未知只报告毛差，不能称净盈利、净胜率或账户优势。归因记录更清楚不等于已证明工程措施改善收益，也不自动改变参数。

复盘节奏和试验期限由事前协议确定；流程进度、技能回写与合成测试不证明盈利或手机到达。写入规则需当前授权、版本冲突处理及同版本读回，聊天总结不等已保存。本公开包不附个体单日案例、成绩或内部运行笔记。
