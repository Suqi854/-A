# 验证流程与日内前瞻合同

本页是事件、分账、基线与统计的唯一规则源；方向、股性、盘面、窗口、价区和阶段依[日内决策框架](../../ashare-position-t/references/intraday-decision-framework.md)，计划字段复用[日内计划记录](../../ashare-position-t/references/intraday-plan-record.md)。规则写入插件不等于已建采集器、事件库、持续监控或自动统计。只使用实际可用接口与运行设施，缺设施时输出待落地模板和缺口，不声称自动追踪、完整事件覆盖、后台独立运行或手机到达。

## 试验冻结与证据层级

事前固定试验ID、父版本、来源URL/commit/作者、证券与成员时点、观察起止、规则/参数版本及hash、生效时间、快慢变体、信号确认、最早可用参考价、目标窗口/失效、退出与未闭环处置、费用口径、基准和评价/终止条件。计划价格有效期与计划期限分开；不得用后来的高低点选择起点、窗口或最好参数。

理论、合成验算、真实样本内、滚动样本外、前瞻报价情景、前瞻纸面账户与真实成交分别出结果。报价情景没有用户明确的纸面数量、现金与费用假设时，只研究价格与路径，不造纸面净收益、净胜率或账户。真实成交价格已含实际滑点，不再次假扣；假设费用与延迟单列，未知不填零。

参数或方法变化建立新版本，记原因、授权与未来生效时点，保存失败、反例、全部候选和选择过程。既有授权覆盖的实施不反复索要确认；未获授权的新规则留候选。新版本不改旧计划、旧机会分母或旧成绩；账户原始持有基线也不随版本重置。

## 全部机会与追加事件

以事前证券范围、可用数据与规则版本定义机会全集。观察/候选阶段即建立稳定opportunity_id，到预警形成计划时再生成并关联plan_id，不能只收录已经预警的计划。每次变化有稳定event_id、递增sequence、修订号、变体与上游证据身份；重试、重复返回与重启读回按原身份去重。同一事件内容冲突追加更正关系，不覆盖原记录；不得按每次轮询新建相同机会。

追加保存预警、确认、更新、失效、到期/结束、抑制与数据缺口及其状态原因；尚未满足、未评估、未触发、主动放弃、未提醒、未采取行动、未成交和未闭环均可对账。不把数据不足写成条件不满足，不因未发提醒或亏损而删样本。若未执行全范围评估，只称已观察机会，报告范围、起止与漏采/未知覆盖，不能宣称“全部机会已留痕”。

事件保留源时间、接收时间、读取版本、评估开始/结束、计划版本和相关quote/分钟/背景证据；提醒另留发出、可观测送达与本人确认，无法核对就UNKNOWN。请求开始/返回耗时、报价源年龄、相邻有效观察缺口、评估延迟和提醒/送达延迟分别记录，最新返回quote不能消除等待期间缺口。日期精度不补分钟，received_at不当known_at，后修订行情只追加修订关系和敏感性分析。落地实现应优先采集与追加事件，慢统计/复盘异步增量汇总，不阻塞采集关键路径；没有实际隔离和耗时证据时仍标未验。

采样覆盖与分析覆盖分别核对：有连续报价或快速刷新，不证明相同期间已经评估规则或作出决定。仅有采样日志而无相应评估证据时，分析覆盖为UNKNOWN；保留最近一次已核评估时刻及之后的缺口，不把该区间自动标成“无信号”。首个纸面quote的源时间已知但独立接收/读到时刻遗失时，后续展示只能证明最迟已见，不能替代精确接收时刻或据此计算精确链路延迟。

预警与确认分别冻结起点、当时目标/失效和期限，分别建报价评估行；同计划两阶段不是两次独立交易。早期观察如尚未冻结目标、失效或评价窗口，保留在全机会覆盖并标UNKNOWN/未具评价定义，不纳入目标命中分母，后补目标不能回填旧观察成功。更新计划另记修订与生效时间，不用后来目标重算旧起点。快/均衡/慢变体在同一原始时序事件与可用性上并行对照，未触发与缺失也记录；保留各自阶段，不对齐到事后最优时刻。各变体的窗口与确认差异在试验开始前另行冻结，本公开包不携带个人变体配置。选定变体的结果和影子结果分组，任何实际成交只记一次，不能复制为多个实际账户或将影子触发当实际行动。

## 报价路径的目标与失效

每个预警/确认起点事前冻结参考价口径、有效价区、目标区域、失效边界、观察结束时间和判定方法。只用起点之后实际收到且当时可得的有序报价路径；同一根OHLC触及目标与失效、同时间戳无法排序、长调用/断档可能漏过边界、旧缓存或时间/来源冲突时，先后为UNKNOWN，不能选择有利顺序或计胜。

记录目标先观察到、失效先观察到、到期未达到、仍开放、路径未知和不适用，附实际窗口与覆盖。目标/失效顺序可知不证明按该价格成交；缺少排队、可成交报价或成交回执不补成交。跨越缺口后才见目标不能默认目标先到；全天极差不算可得利润。需“提醒后首个核验quote”的纸面协议时，源时间必须严格晚于提醒时刻，同秒精度无法证明更晚就留缺失；此协议不改写真实成交。

纸面首价协议与执行资格分列：若已冻结的计量协议要求保留提醒后首个可核验新quote，即使该quote已超出原有效价区或与不追价条件冲突，也保留原quote和毛差并标“越界/执行不合格”或资格UNKNOWN，不改选后来的有利价、不补成真实成交。全部纸面样本及异常计数仍报告；不得把越界纸面正毛差计入合格执行成功数。若另报合格执行子集，事前冻结资格与分母，列总样本、合格、不合格、UNKNOWN及覆盖，不能删掉异常后宣称总体策略更优；既有净胜率定义不由该子集替代。

报价统计按规则版本、变体、预警/确认阶段分别报总机会、目标先到、失效先到、到期未达、开放、未知及路径覆盖率。目标到达率=目标先到数/(目标先到+失效先到+完整观察至固定窗口结束而未达数)，零分母为UNKNOWN；路径不能判顺序或不能证明完整观察至到期的保留未知。它不是成交胜率，也不是扣费净胜率；另列可评估数/总机会覆盖率，开放与未知不能默默从总体表现消失。

## 真实成交与未闭环

成交仅关联既有确认账本及真实回执；新增输入先草稿→本人确认，已有确认直接复用。保留证券、方向、实际数量、实际价、实际成交时间、实际费用或UNKNOWN、execution_id与账本版本，更正追加链；缺失字段不从计划或quote推算。稳定成交身份防重复关联，分批成交与费用补确认保留原关系；确认录入实际数量不等于建议下单数量或授权自动下单。

订单提交、部分成交、撤单请求/确认、剩余有效量和到期分开；人工撤另一单不保证互斥。库存、可卖旧股、当日新买T+1锁定、现金和未完成两腿按[做T记账](../../ashare-position-t/references/inventory-and-legs.md)。费用未知可以继续方向观察、记录真实成交和敞口，但所依赖的净结果为UNKNOWN；真实违规成交如实记差异，不拒收、改量或删除坏样本。

每个T周期保留首次意图、两腿与部分数量、期限、退出受阻、残余仓位及期末估值。T失败或未闭环之后决定永久加减仓，另记新决策与生效时点；原T的失败、机会分母、费用与残余风险继续保留，不能改名“动态调仓”后消失，也不能事后延长原窗口洗掉失败。

实际已闭环T净胜率=正净结果闭环数/(正净+负净+零净结果闭环数)，分母仅为两腿数量完整可核、费用齐全、周期归属确定的闭环T；同时列盈利、亏损、持平、开放、部分/未闭环、费用未知、归属未知、总周期数和可评估覆盖率。零分母写UNKNOWN，不报0%或100%。部分闭环如需分配成本须有事前明示方法，否则保留未知；局部净价差不能替代全账户优势。

## 可复盘指标口径

按版本、变体和证据层级分别列值、单位、分母/区间、覆盖及UNKNOWN原因；没有数据不补数值，报价指标不混成实际账户收益。

| 指标 | 口径与缺项处理 |
|---|---|
| 平均净结果 | 全部费用已知且完整闭环T的净结果总和/该闭环数，持平计入；缺费或未闭环另列，不混入已知净均值 |
| 平均盈利/平均亏损 | 正净闭环结果总和/正净闭环数；负净闭环损失绝对值总和/负净闭环数，明确亏损为绝对额；对应零分母为UNKNOWN |
| 最差日 | 同冻结基线下、资金流与费用可核的实际日权益净变化最小值，注明日期与有效日数；同时可列相对持有的最差日，不能把局部T毛差称账户最差日；日估值或资金流不清则UNKNOWN |
| 未闭环浮动结果/持续时间 | 依剩量、当时有效估值和可核费用单列敞口及相对原持有的浮动变化，不计闭环净胜；自首次实际成交至当前/闭环的历时，若另报交易时长须有交易日历/时段证据，缺价费或时序则相关值UNKNOWN |
| 预警提前量 | 同一plan预警至确认的时间差，源时间、评估时间和可观测送达口径分列；未确认、未送达或精度不能排序则UNKNOWN，不把取数频率当提前量 |
| 有效价区持续时间 | 自该版本价区生效至首次退出/失效/到期的已观察时段，注明采样分辨率；缺口内是否仍有效不可知，给有据区间或UNKNOWN，不跨断档推定连续有效 |
| 假突破/重复/过期提醒 | 假突破按核心事前冻结的突破确认、随后失效与窗口计数/同定义可评估确认数；未定义或路径未知不贴成功/失败标签。重复提醒按相同事件身份和消息阶段核多余发送；过期按当时有效期核发送/可观测到达，未掌握到达时刻则送达过期为UNKNOWN |
| 剩余空间 | 以当时有效报价至沿预期路径最近有据障碍/目标的方向性价差及明确分母的比例，按核心价区与时间版本记录；不越过中间障碍、不用全天极差，缺quote/障碍或口径则UNKNOWN；无数量费用不算账户可得净利润 |

## 跨日冻结持有基线

在前瞻起点冻结原始证券/数量、现金、时点、估值口径、账本revision/hash与baseline_id，并沿用至本次试验结束。不能每天以当前仓位或剩余现金重新起算，不能因规则更新、亏损或新调仓重置基线。资料缺失先标UNKNOWN；发现错误以可追溯更正同时保留原版，不能悄悄改出更优结果。

每个实际交易日用同末时点、同未复权/公司行动口径估值：实际路径重建全部真实成交后的动态持仓、现金、已知费用与未闭环敞口；持有路径维持原始底仓并按同一已核公司行动处理。逐日列实际总权益、原始持有总权益、当日变化与自固定起点累计差异；实际账户不能只选关联到策略的盈利成交，也不能把其他调仓或资金流隐去。

已核外部入出金按同额、同生效时点进入实际与持有两条路径的现金账户，或采用事前固定且对两路径一致的现金流调整收益方法；新增现金在持有路径保持现金，不能事后补买原底仓。原始底仓/起点现金与baseline_id继续冻结，另记各笔外部流，不重置基线。共同外部流本身不算收益或策略优势；例如起点两路径均1000、无交易无涨跌，随后共同入金5000时两路径均6000，相对优势为0，不能记成5000盈利。每日/累计收益、最差日及回撤采用同一事前现金流调整口径，已核出金也不能直接记作日亏损。提现若令冻结持有路径现金不足，不虚构借款、不偷偷卖底仓；须有事前声明且可核的可比调整方法，否则该区间持有对照为UNKNOWN并列影响。已知公司行动也按同一适用证券与生效时点对称处理，不能重复计分红。

外部入出金、分红送转/拆合等公司行动、起点现金、期末价格或费用缺少可比证据时，相关权益、净收益及相对优势为UNKNOWN，列出所依赖缺项；不能假定“无资金流/无公司行动”。已知方向与价格事实仍可报告。持有浮动损益、局部T净差和账户累计优势分列。

只有真实、按时序且覆盖说明充分的权益路径才计算最大回撤，并标日频/更细频率、起止、缺口和所覆盖区间；日频不冒充盘中最大回撤。仅起末两点、断档路径或未知权益不算完整回撤，不能用0替代。尾部、水下时间、集中暴露和换手也仅在各自数据可核时计算。

## 前瞻观察与定期复盘

事前冻结观察期限与复盘节奏，按实际有证据的交易日期去重累计；休市不计，整日或局部缺口单列，不因日期已经过去自动计完成。

每次复盘按同一事件集比较已冻结变体：机会与各阶段分母、先后与错失、路径覆盖、UNKNOWN、成本/延迟敏感性、真实行动、净结果、未闭环及相对冻结持有基线。不得以本窗口最好结果直接替换现场规则；新规则另建未来版本。

分别列机会数、实际闭环数、有效日期数、开放/未知及不确定性。同股多笔、市场共同冲击、重叠窗口、预警与确认及同源指标均相关，不能把行数当独立样本；需要时按日期或证券簇核稳健性。完成观察期或复盘次数只是流程里程碑，不证明统计显著、稳定盈利或提醒可靠。

## 滚动样本外与结论

按时间训练→验证选择→冻结→后续测试，拟合、标准化、特征与风险模型只用当时已知资料；重叠标签/窗口需要时隔离purge/embargo，不随机打散未来样本。看过后调参的区间记已使用，再用后续新数据。检查PIT成员、存活偏差、复权修订、后来财报、现时行业名单、交易规则日期、涨跌停排队、现金和库存约束；资料缺口不宣称无前视。

固定相同范围、起点、期间、执行约束与费用，对照简单规则、持有基准及复杂方法，报告阶段差异、参数邻域、最差已观察情景、成本与延迟敏感性，保存失败和不可行状态，不静默放松条件。不能仅靠胜率宣布升级优于旧版：收益改善没有相应证据、可比回撤恶化或未闭环风险上升时，不宣称整体优越；风险收益取舍需明确披露并按未来规则处理。高胜率不等正期望，VaR/ES或历史最差不是损失上限。未运行、源不足、路径未知、未验证、有限结果与真实成交分别表述；有限通过也不承诺实盘可靠或盈利。

| 事件与报价评估 | opportunity_id、event_id/sequence、plan_id（预警前可空）/revision、阶段、源/接收/评估时间、证据版本、冻结目标窗口或未具评价定义、路径结果及UNKNOWN原因 |

| 定期复盘 | 实际日期清单、版本/变体/阶段分母、闭环/未闭环/UNKNOWN、成本延迟、相关性/不确定性、反例与未来候选变更 |
