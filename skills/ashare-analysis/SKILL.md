# A股分析与决策路由

本技能的数值输出先遵守[统一核心结果引用合同](references/data-coverage.md#统一核心结果引用合同)：只引用核心原结果，不自行重算；逐项保留 result_id、source_trading_date、fetched_at、core_version、data_coverage、validation_status 的原值或“待绑定／未知”。本页及后续材料中的公式和计算口径只供解释核心结果；拒绝、参考价、历史/前瞻/真实成交的区分均按该合同，缺原结果就给结构条件与缺口。

先用一两句回答“目前首选什么、为什么”。没有已确认目标时默认关注数周波段；本次或已有日内做T/调仓目标优先并持续复用，不每轮重置成波段。依问题处理行业选股、量化验证等，不强制走完所有技能。等待、继续持有、减少操作也可以是首选。

本包提供分析流程；行情、账本、提醒和同步能力须运行时发现并验证，不能因技能升级宣称接通。先读共享[数据规范](references/data-coverage.md)与本题相关部分；只读对应专门材料。

## 得出可行动的条件判断

- 先核证券唯一身份、研究期限和源时间；同名歧义不选第一条。按照实际工具schema取必要窗口，不猜接口或参数。
- 先看价格位置、结构和成交，再用指标辅助；K线、均线、MACD多为同源，不能相乘出高胜率。“主力意图”只作解释假设并给替代解释。
- 确认使用事前选定且真实完成的证据窗口；连续真实采样与已完成K线分别核验，不统一等待任意根数或所有周期。详见[日内决策框架](../ashare-position-t/references/intraday-decision-framework.md)。
- 价格、行业与消息时间不齐时缩小对应结论，不伪装同步。缺项只限制依赖它的部分：费用未知不报净利；库存或现金未知将执行标为待核；财务PIT不足只阻止相关历史财务结论。已有行情、经营事实或纸面情景继续分析。
- 不为凑候选放宽规则，不因亏损默认加仓或每天做T。方向候选与执行资格分开；风险、空间或所选触发不支持时首选等待，未知费用不自动否决已有量价观察。估算、历史回放、当前观察和真实成交分别标注。

买卖问题给“首选＋两三条事实依据＋触发/失效＋备选”，必要缺口紧随相关结论。价位有本次数据或明确计算依据；没有依据就给结构条件。不给未经校准的概率、必到目标价或保证收益。普通报价不套长表。

## 盘前、盘中、盘后

- 盘前：普通个股分析对本次指定的重点股给首选计划、关键区域、条件和失效处置，标出隔夜事件与最新数据缺口。已授权的早晚市场简报按[会话简报](../ashare-session-briefing/SKILL.md)覆盖当前本人账本全部持仓，不以重点股上限截断；其余任务沿用已有最小读取范围。
- 盘中：做T与动态调仓共用[日内决策框架](../ashare-position-t/references/intraday-decision-framework.md)的股性/盘面/量价、四类候选、唯一计划与方向协调，不另起一套相反建议。重要状态用“【重要】”突出，阶段去重、报价时效、计划版本与风险动作统一按该框架。
- 盘中留痕使用[计划记录](../ashare-position-t/references/intraday-plan-record.md)，保留当时已满足/未满足条件、数据时间、证据、价区、下一触发及失效。候选未触发、已触发未提醒、未行动、未成交分别保留，不把零提醒等同于无机会，不补不存在的交易。事前定义的采样目标、源更新、实际读取与提醒送达是不同运行指标，均以实际能力和回执为准。
- 盘后：成交复盘用当时计划和已确认成交，区分判断、执行、数据与结果；全市场晚间复盘路由会话简报。二者关联同一账本和未闭环计划，增量学习转策略验证，不把单日赚钱写成有效规则。

本技能不发单、开户或转账。持续观察、送达、手机后台、云同步须有相应实现和实际回执；按当前连接、配对、同步版本及实际回执判断状态；缺回执时保留待核，不预先承诺已同步。平台发布与实际宿主加载新版分别验收，不能因发布成功宣称当前会话已采用新规则。旧部署、学习和验收记录只在追溯时读[历史索引](references/history-index.md)，不作为当前运行状态或日常必读。
