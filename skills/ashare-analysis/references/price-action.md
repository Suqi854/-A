# 量价、趋势与条件路径

数周波段以日线结构和周线背景为主；日内按[日内决策框架](../../ashare-position-t/references/intraday-decision-framework.md)使用事前定义、真实可得的采样窗口及各周期结构。采样确认和K线收盘确认分别核证据，形成中不当已完成。大周期偏弱与局部反弹可同时成立，缺周期只限制对应结论。

先取可追溯的前会话高低、已确认转折或重复成交区域，注明日期、窗口、复权与算法。用户成本不是支撑；右侧确认型转折的最早可知时刻在确认之后，不能倒填。

按三层证据形成首选，不用一个总分掩盖缺口：

- 股性画像：用可追溯历史窗口描述波动、流动性、常见回撤/推进及成交特征，记录样本数、日期、可比性和版本；画像只是先验背景，不能代替当前触发。缺事前定义的所需历史时相应画像UNKNOWN，不从当前几笔走势补造长期股性。
- 当前盘面：位置、高低点序列、回撤/反弹、与大盘/板块同期相对表现及实际可得消息。未知、陈旧或不同步的背景单列，不赋中性分；按[大盘与信息](market-and-news.md)限制依赖它的结论。
- 滚动量价：同单位、同源、同时间尺度的真实量额与价格推进/衰减；区分价格继续前进、成交增加但推进减弱、突破后回落和缩量回撤。均线/MACD仅作少量辅助并注明预热/完成，不将同源派生指标累加成独立概率。

每层列支持、反证和缺口，再形成候选方向。画像或盘面偏强不自动触发快窗计划；一项局部条件满足也不能覆盖证据断流、相反风险或未闭环状态。

“站稳、放量、突破”说明采用真实采样窗口还是已完成K线、边界、覆盖和可比基准。一次越线、重复快照或轮询次数不构成持续确认；真实窗口推进则不必等一根无关大周期K线收盘。声称相对历史同一时段放大时，须有[共享数据规范](data-coverage.md)规定的历史同时刻基准；缺基准不能给“历史显著放量”。本次同源、同单位、等时间尺度的回落较前段缩量或恢复推进较回落放量可独立比较，明确比较对象及覆盖，不冒称历史同时刻结论。数量/缓冲/持续长度来自核心既定版本或标明待验证假设，不能因当前结果临时调参。固定日线筛选由[筛选契约](../../ashare-swing-screen/references/screen-contract.md)定义。

推进与衰减必须把“用了多少交易时间/量额、价格实际前进多少、回撤有多深、后续是否继续”放在同一窗口比较。成交变大而价格几乎不再推进可作衰减证据，不能单凭放量认定吸筹或突破必成；低量也可能是流动性不足。没有逐笔就不推断主动买卖、撤单或全量订单流；只有快照就保留采样间路径未知。切源、累计回退、午休及断流后的重建期间，不沿用旧窗的推进计数或确认票。

一般给一个首选情景和一项备选，分别写支持事实、触发、失效及下一观察区域。日内计划价区、目标、失效、证据、报价新鲜期与计划期限分别标明，采用核心文档的唯一生命周期与阶段通知规则；缺关键输入时降级/终结相应计划，不把旧有效状态留给界面继续执行。目标区不是必到价格，情景不伪装校准概率。只有OHLC不决定同根路径顺序；没有金额不算精确VWAP。主力吸筹/洗盘/出货均为待证解释，并保留替代解释。

实际操作再读[持仓做T](../../ashare-position-t/SKILL.md)。趋势偏强未必适合追价，偏弱也不创造可卖量或保证退出。价位、库存、损失预算各用对应证据；缺一项只限制依赖它的动作。
