# 共享数据规范

本页是七个技能的当前共用口径。按任务读取对应小节；历史版本与学习记录见[历史索引](history-index.md)，不默认载入。技能只写流程，不能创建行情、L2、账本、监控或云同步实现。

## 统一核心结果引用合同

`A-` 维护可执行能力与网页，`-A` 维护分析流程和方法说明。数值规则由统一核心实现产生；七项技能只引用原结果、解释含义与缺口，不自行重算价位、指标、筛选评分、估值、费用或绩效，不用手算、脚本、替代公式补出第二套结果。本包其它材料中的公式、求差、估值与统计口径均是给核心实现及结果解释的要求，不授权技能执行计算。缺核心输出时继续描述已有来源事实、结构条件和待核项，相关数值保持未知。

下列名称是本轮约定的**引用目标**，不是已核实存在的响应字段或新接口。本公开包没有统一核心的运行时schema；逐项真实字段路径、类型、可空性、枚举及语义均待绑定。绑定须保留具体schema/源码锚点与同版本脱敏原响应；映射只引用，不推导、不拼装伪核心对象。

| 引用目标 | 原样引用及解释要求 | 缺失或冲突时 |
| --- | --- | --- |
| `result_id` | 引用核心原结果身份，关联同一结果的说明及追加版本 | 写“未返回／待绑定”；不拿预览ID、计划ID或技能自建ID冒充 |
| `source_trading_date` | 保留结果实际来源交易日及原精度 | 不用今天、抓取日、工作日或最近一条日期推算 |
| `fetched_at` | 保留核心所报取数时刻、时区、精度及其实际语义 | 不用回答时间或本地读档时间补写，不等同源事件时间 |
| `core_version` | 引用产生该原结果的核心版本，另列技能版本 | 不用网页、行情服务、插件或候选源码版本替代 |
| `data_coverage` | 引用原覆盖范围、输入/有效样本、周期、期间和缺口等实际返回内容 | 单列未知项，不把输入条数升级成有效成交或全市场覆盖 |
| `validation_status` | 引用原状态及原因，说明它验证了什么、未验证什么 | 不自造枚举、不翻译成通过；schema未核时写“待绑定” |

保留原结果引用可得位置及证据截止；涉及多个结果时逐项绑定，不将不同日期、核心版本或覆盖的字段混成一个结果。候选冻结预览ID与 `result_id` 分列，父版本、数据版本、策略/方法版本有原结果就原样引用，没有就待绑定。不得以技能版本填充这些字段。新增解释或新数据追加版本，旧预览、旧结果和拒绝原因继续保留。

### 拒绝、未知与参考价

- 核心明确拒绝或默认拒绝时，引用原回执与原因，保持对应动作不可执行；不把候选存在、预览成功、价格触及或源码适配解释成准入。没有回执写“执行资格未知”，同样不得当作许可。不得绕过拒绝去另一方法重算一个可执行结果。
- 费用未知时保留费用未知、净绩效未知；零成交不等于已验证收益为零。缺失、禁用、不适用、未验证、拒绝与有效结果为空分别解释，不统一写成失败或零。
- 参考方法的价位只是有来源的观察/解释结果，**参考价不是交易策略**。不能由单个参考价自动派生买卖信号、止盈止损、仓位、成交或盈利结论；没有统一核心给出的原价位就只给结构条件，不自行计算。
- 缺已核锚点、开盘数据或量额等依赖时，保留原禁用/未知原因，不能用收盘价、相邻分钟、补零或反推值开启方法。布林预览源码适配只说明候选代码阶段，不代表已加载、可交易或已获绩效验证。方法数量按真实身份与覆盖记录，不将至少五项误当最多五项，不为凑数启用缺证方法。

### 历史、前瞻与真实成交

| 层级 | 可解释的证据 | 不能升级为 |
| --- | --- | --- |
| 历史输入与回放 | 核心原覆盖、当时可得数据、冻结方法及原回放结果 | 输入覆盖不等于有效交易；后验重放不等于前瞻或实盘 |
| 前瞻影子 | 冻结预览/父版本/数据版本之后真实新增的观察、时序及原结果 | 后补历史、合成样本、提醒或触价不等于真实成交 |
| 真实成交 | 本人已确认或实际执行端可核的成交事实，关联当时结果与真实/模拟模式 | 委托、回执受理、提醒、预览均不能补成成交 |

分别报告三个层级的覆盖、有效样本、未知与未闭环；只引用核心原统计，不在技能内计算净收益或胜率。即使具有真实600日输入覆盖，没有有效成交也不能宣称策略有效、全生产可用或具有净绩效。历史修订、候选冻结和未来新规则不倒改旧证据。

## 运行时能力与证据

以当前会话实际schema、连接状态和调用结果判断能力。以下入口及[私人接入通用合同](private-account-contract.md)仅作能力参考，发现、发布、接口成功、数据完整及宿主验收分别报告。不把固定版本、工具数量、源码存在或历史状态当作当前事实；未发现接口不猜命名空间。

可发现的名称包括 `a_get_quotes`、`a_get_bars`、`a_get_intraday`、`a_get_macd`、`a_get_market_context`、`a_get_stock_context`、`a_get_auction`、`a_get_archive`、`a_get_diagnostics`、`a_get_mainboard_universe`、`a_get_stock_directory`、`a_get_stock_pool`、`a_get_swing_screen`、`a_get_auction_snapshot`、`a_get_auction_series`；环境可能加命名空间。没有可用schema时不猜参数，不把文档工具名当调用证据。

报价/分时/K线/指标/背景只取本题需要的窗口。工具不可见、限流、失败、权限不足、陈旧、部分覆盖分别说明；null不当零，失败不当零候选。遵守工具现有限流、超时和重试语义，不因普通分析自行读密钥、改鉴权、恢复暂停云桥或主动诊断。允许已有独立数据继续研究。

## 时间、质量与价格

- 中国交易时点用Asia/Shanghai。分别保留源时间、接收时间、会话日期、周期标签及研究截止；只有日期保留日期精度，接收/读档时间不能代替历史known_at。
- 名称须唯一精确匹配并核代码/市场/报价身份；近似、截断和冲突保持未知。源延迟未知就不称实时，最近会话不默认今天。
- 单位按来源定义，个股价格与指数点数、股/手、元/万元、累计量与区间量分开。缺成交额不算精确VWAP；跨午休或数据缺口差分不称一分钟成交量。
- 历史信号使用一致复权口径；实际成交、库存、费用和委托参考用当时未复权价格。不能把复权支撑直接当当前交易价，也不混拼不同来源来凑窗口。
- 周期完成要求只作用于依赖该周期的规则。真实连续采样可确认事前定义的滚动条件；形成中K不能冒充已完成K。各周期分别核完成与连续性，不将所有周期齐备设成统一等待门。
- 使用K线时检查工具实际提供的completion_cutoff、calendar_completion、source_finality及逐条质量；字段不存在就不造。服务若以时间门槛推定完成，该门槛仅为保守日历推定，不等于交易所最终值认证；时钟跨线不能升级旧盘中缓存。MACD预热和分钟缺口另核。
- 分钟条形与complete标签可能被来源后续修订。复盘用决策当时取得的版本与其完成证据，后取得版本另作修订说明；单源complete不等交易所最终认证，不能把后来标签倒填成当时已完成。
- 来源明确标为旧档或stale_fallback时保留原日期/时刻与降级说明；不能静默当新行情。档案只是已观察窗口，不证明上市全历史、所有修订或连续后台采集。

## L2、快照与分钟

普通研究按当前授权范围选重点；获授权的[早晚会话简报](../../ashare-session-briefing/SKILL.md)须逐只覆盖当前本人账本全部持仓，并单列缺口，不将此例外扩展到其它任务。优先使用已获许可、字段和时序已验证的L2；先核产品权限、逐笔/委托字段、订阅范围、源时间、漏序/断线及价格量单位。

同花顺消费L2会员、程序接口权限与逐笔授权分别核实。[官方iFinD FAQ](https://quantapi.10jqka.com.cn/gwstatic/static/ds_web/quantapi-web/help-center/faq.html)仅作核查入口；以当前产品、字段、来源和授权证明能力，不索取或输出凭据。

L2未接通时，可按当前任务选择真实快照与分钟结构的降级方案。采样周期和时效预算须事前声明并实际验证；请求间隔不等于源更新间隔，未实测不称可靠提醒。单时点五档、重复快照及分钟差分不改称L2或逐笔，缺撤单数据不推算撤单率。

### 采样窗口、去重与重建

- 事前定义的滚动窗口由真实连续样本按源时间滚动构成，保留接收时间、来源身份与版本。它描述已采样路径，不证明窗口内全部成交；快照之间的价格、成交顺序和短暂触价均不可补造。只有分钟OHLC时不能拆出更短周期的真实轨迹。
- 新源样本驱动评估；没有新源数据的状态检查只检查过期、断流和撤销，不把轮询或相同报价重复计票。相同源事件/内容去重；同一价格但源时间与累计量等真实变化可构成新样本，不能仅按价格去重。缺源时刻/样本身份则明确新鲜度未知。
- 迟到、乱序样本保留到达事实与质量标记，不倒写已发计划、已确认条件或过去决策。来源更正作为新版本，关联受影响计划；不得把后来取得的数据回填为当时已知。切源后给依赖旧窗口的当前计划追加“待新窗口复核”，必要时追加失效事件；原确认、原版本及证据完整保留。随后按新来源重建，不拼接凑足窗口，也不抹改历史确认。
- 区间量额仅从同源、同会话、同单位且时间递增的累计值求差；累计回退、交易日切换、午休前后、断流或缺口均划断连续窗口，恢复后重新建立锚点。午休不计入连续交易秒数，也不把整段跨午休差分称一分钟成交。未积累足够真实覆盖就显示窗口重建/UNKNOWN。
- 同时刻量额基准使用研究时点之前的同一时段与同口径样本，窗口和最小样本量事前定义；缺有效日期、覆盖、单位、来源或足够样本则基准UNKNOWN。不能以全天均量、当日累计量、任意相邻分钟或不足事前样本要求的均值冒充该基准。成交额缺失时量额基准分开标记，不补零、反推成交额或声称精确VWAP。日内当前数据不能进入自己的历史基准。

### 运行接入与时延证据

下列为采集/运行端的接入要求，技能文字本身不会建立采集器、后台线程或推送服务：

| 环节 | 保留的时点/状态 | 不能替代的证据 |
| --- | --- | --- |
| 数据源 | 源事件时间、来源及质量 | 本地接收时间不能证明源实时 |
| 本地接收 | 首次取得该新样本的时间 | 再次读缓存不是新接收 |
| 分析 | 开始、完成及绑定的样本/计划版本 | 源延迟与分析耗时分开 |
| 通知队列 | 入队、出队、取消及所用计划版本 | 入队不是发送 |
| 发送 | 传输开始、返回、失败或UNKNOWN | 请求完成不等平台受理 |
| 平台 | 受理回执及查询状态 | 平台受理不等手机收到 |
| 手机 | 本人本次实收确认及可得时间 | 旧测试或其它事件实收不能继承 |

本地接收、分析更新、排队、平台和手机的时延分别测量，报告范围、样本数、分位数、缺失、超时及版本。工程目标来自当前获授权配置；未实测保持NOT_VERIFIED，不将合成耗时、均值或单次成功当作实测分位数。缺时点不推算。

采样关键路径只处理受新样本影响的标的与其共享背景依赖；额度、凭据、网络发送和重汇总须隔离为有界慢任务，保留超时、背压、取消和失败UNKNOWN。状态检查独立核验报价TTL、断流与作用域/配置变化；报价新鲜期与计划有效期分别校验。发送前重验真实证据、当前计划版本、作用域、价区、有效期、手动暂停和共享额度，旧版队列撤销；UNKNOWN不自动重试。具体阶段去重和重大风险规则只引用[日内决策框架](../../ashare-position-t/references/intraday-decision-framework.md)。Windows提示、手机和界面都应跟随同一计划撤销/版本；文档通过不证明上述接入已经实现或后台独立运行已验。

## 竞价、截图与专项字段

竞价分钟点、09:26来源标签、开盘价与截图终态不等于完整竞价过程或已核最终撮合。只解释实际有的字段、阶段和覆盖；未来、重复、错序或跨会话数据不自行修复。

截图核证券、软件、日期/光标、周期、坐标及量柱定义；关键数值看不清就只作观察。图表疏密不计参与人数、筹码数量不计股东人数、龙虎榜营业部金额不计完整账户持仓。量比与主动成交方向须有来源定义；OHLCV不能唯一还原逐价成交量、队列或高低价顺序。

## 行业、公开池与财报

背景榜单的分类、时点、范围须与个股一致。新浪分类、主题标签或热点成员不自动等于申万三级；时间未知不算实时超额或确定轮动。

`a_get_stock_pool`按实际schema读取公开研究快照，核pool_id/版本/hash、来源日期/分类与覆盖等实际返回证据；没有字段不补造。快照不自动证明全申万三级、各行业的经营龙头目标覆盖、历史成员或已完成筛选；见[筛选契约](../../ashare-swing-screen/references/screen-contract.md)。

财报保留原报告、公告编号/URL、页/表、报告期、主体、币种单位、披露精度及更正链。当前修订事实可作当前研究，历史研究只用当时可得版本；单位/PIT缺口只限制相应计算，不阻断其它已支持内容。

## 授权、留存与执行

公开行情可在已授权、实际来源政策支持的范围内查询/缓存/留存；遇服务禁止新增留存或许可未知须遵守其明确边界。技能更新不改变服务器、存储、连接或旧凭据状态。

持仓与成交按[账本与同步](ledger-and-sync.md)处理，以当前任务授权为准。真实或模拟个体记录、个人资料、凭据、私有运行源码与策略参数不进入公开插件包。读取、同步、外发及公开分享分别授权，技能文字不继承任何个人既有授权。报价、提醒、委托、撤单请求和实际成交是不同事件。

T+1、数量、限价、竞价/撤单及费用按具体证券、市场和适用日期核官方规则；当前或教材规则不回填旧时期。只读行情不能证明排队成交。费用未知不称净收益，触及止损不保证成交或损失上限；不能为了完成分析而自动交易。
