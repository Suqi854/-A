# A量化引擎（本插件内置）

引擎代码在插件目录的 `engine/` 下，只用 Python 3.10+ 标准库，不需要安装任何依赖。行情来自腾讯财经和东方财富的公开网页接口，需要能访问 `qt.gtimg.cn`、`web.ifzq.gtimg.cn`、`push2.eastmoney.com` 和 `push2his.eastmoney.com`。如果访问不了，就改用 `aq-terminal` 技能读已经发布的公开数据。

## 命令

以下命令都在 `engine` 目录下运行；加 `--json` 可以拿到原始数据。

| 用途 | 命令 |
|---|---|
| 大盘总览 | `python -m aq5.cli market` |
| 实时报价 | `python -m aq5.cli quote 600519 000858` |
| 个股分析 | `python -m aq5.cli analyze 600519` |
| 立即选股 | `python -m aq5.cli pick`（扫描全主板，约 1~3 分钟） |
| 回测 | `python -m aq5.cli backtest 600519 [score\|breakout\|pullback\|volume_start\|oversold\|macd_cross\|accumulate]` |
| 读公开数据 | `python -m aq5.cli public latest\|picks\|ai\|learn` 或 `public analysis 600519` |
| 启动网页终端 | Windows 双击仓库根目录的 `launch.cmd`；其他系统运行 `python -m aq5.server`，然后打开 http://127.0.0.1:18950 |
| 离线演示 | 设置环境变量 `AQ5_MOCK=1` 后运行任意命令，使用模拟行情 |

数据默认存放在 `engine/data`；如果这个目录不可写，会自动改用 `~/.aq5`。

## 方法说明（回答用户“为什么”时用）

- **9 个因子**：动量、趋势、量能、资金（主力净流入占比）、强度（相对大盘）、波动（ATR%）、估值（PE）、位置（距60日高点，过热扣分）、流动性。每个因子用 logistic 映射到 0~100 分，再加权合成。
- **8 种策略**：趋势突破、多头回踩、放量启动、超跌反弹、MACD 金叉、主力吸筹、尾盘强势（14:45）、竞价抢筹（9:26）。
- **综合分** = 因子分 × 0.75 + 策略分 × 0.25。评级分五档：≥78 且站上 20 日线为「买入」，≥68 为「轻仓试错」，≥52 为「观望」，≥40 为「减仓」，更低为「回避」。
- **交易计划**：止损取 2 倍 ATR 和下方支撑位中较近的一个，最多 -8%。止盈①为 1.5R，到达后卖一半，并把止损移到成本价；止盈②为 3R；最多持有 10 个交易日。
- **主力行为**：用近 5/10 日主力净额、价格变化和量能，判断属于拉升、吸筹、洗盘、派发、撤离中的哪一种，还是不明显。
- **选股门槛（宁缺毋滥）**：综合分 ≥72，且至少有一个置信度 ≥0.5 的策略信号、盈亏比 ≥1.4、RSI6 不超过 88。大盘处于震荡时门槛 +2 分、最多 3 只；空头时 +5 分、最多 2 只。
- **自我迭代**：把每次选股的前 150 只候选存为样本，之后回填 1/3/5 日收益。用 Rank IC 平滑调整因子权重（每次最多变动 30%，单个因子权重限制在 2%~30%）；样本 ≥10 后按胜率调整策略权重；样本 ≥200 后训练逻辑回归，用时间外检验，AUC ≥0.55 才启用。另有「历史冷启动」：在历史 K 线上回放，生成上万个样本。

## 回答规范

- 先说数据时间（报价里的 `time`）和当前交易阶段，再说结论。
- 个股分析按「评级 → 交易计划（具体价格）→ 主力行为 → 理由 / 风险 → 学习要点」的顺序输出。用户在学习，要解释为什么。
- 选股结果为空时，明确说明「宁缺毋滥、建议观望」。
- 这些都是模型输出和模拟交易，不连接券商、不下真实订单，不构成投资建议。
