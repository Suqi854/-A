# 成交事实、归因与经验

新增输入走草稿→本人确认，已有确认账本直接复用。真实/模拟身份、更正与同步回执依[账本契约](../../ashare-analysis/references/ledger-and-sync.md)；全机会事件、报价路径、实际净胜率、未闭环、冻结基线与事前协议规定的统计统一依[验证流程](../../ashare-strategy-validation/references/validation-protocol.md)，不在本页另立分母或阈值。

## 最小复盘卡

按实际可得记录，缺失留UNKNOWN，不为完成表格编值：

| 内容 | 核对字段 |
|---|---|
| 事前意图 | plan_id/版本、生效时点、做T或动态调仓、方向、有效价区/目标/失效/截止、未闭环安排、当时证据 |
| 时序与覆盖 | 源/接收/评估、预警/确认、提醒发出/可观察、委托、部分/全部成交、撤单请求/确认、延迟与缺口 |
| 实际成交 | ledger_id/revision、execution_id、证券/方向、用户确认的实际数量/价格/时间/费用或UNKNOWN、周期/腿、回执与更正关系 |
| 库存现金 | 起点总量/可卖旧股/T+1冻结、现金状态、每腿剩量、未闭环/隔夜敞口、同末时点估值 |
| 结果与归因 | 毛差/净差及费用缺口、报价与真实结果、相对冻结持有基线、数据/方向/规则/执行/本人新决策、无法分辨的原因 |

新增实际成交缺少数量、价格、成交时间或明确本人确认时先补相应事实，不以计划、触价或提醒补齐；费用未知可留空。既有execution_id再次出现先核原记录与更正关系，不能重复入账或把同一成交复制给快慢变体。真实数量用于事实记账，不从它推导建议仓位/下单数量。无记账回执不称正式记账完成，明确确认的成交事实仍可单独标为“已确认、待记账”，不降格伪装成纸面。

## 价格与责任归因

提醒参考价reference、后续纸面quote与真实成交价fill分列；参考价区间保留原区间或事前比较口径，不事后挑端点。价型和时点可比时，卖fill/quote高于卖reference、买fill/quote低于买reference分别改善该腿价格；反向才是不利偏差。更有利卖价本身不能归因为亏损原因，提醒后价格变化也不单独证明延迟致亏。

按当时可得信息审查计划→信号→提醒→委托→成交→库存/现金→结果，分别解释方向判断、空间是否被中间障碍截断、两腿差价、数据/评估/送达延迟、排队与执行限制和本人偏离/新决策；不能分清就UNKNOWN。后来高低点、行情修订或一笔亏损不证明当时可得利润或某个阈值必错，不把所有亏损归动作慢。

补读历史证据后才发现旧失效条件曾被满足时，分别保留原规则、可核的源事件时刻、实际获知/评估时刻及处置时刻。无法核实当时已知或边界先后时仍标UNKNOWN，不把补读改写成当时已处理。当前风险按当下有效信息处置；后来有利纸面价不消除历史失效、处置延迟或执行不合格。原损益和过程评价分列，不重新挑失效点或最佳成交点。

## 未闭环与新决策

保留第一次意图、原定窗口、两腿部分量、未成交、费用缺失、退出受阻及期末剩量/估值。原T失败后决定继续持有或永久加减仓，新增决策及未来生效时间；原T失败与残余风险、累计权益路径仍保留。不能延长旧截止、重置持有基线或改名动态调仓，使失败从机会/实际分母消失。局部配对价差、持有浮盈和账户累计优势分列，不把仅闭环胜率当总体表现。

## 经验版本

经验ID包含日期、问题/市场状态、证据范围、观察/候选假设/验证状态、反例/失效和下一验证；同义条目追加证据，变化登记新版本。新方法附可核原作者/机构URL与版本，既有授权规则直接落实，未经授权的未来改法留候选；新生效规则只作用后续机会，不修改旧计划、成交和成绩。

单日盈利、用户确认、技能回写或观察期进度均不证明可靠胜率、净优势或手机已到达。
