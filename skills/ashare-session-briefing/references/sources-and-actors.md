# 来源、范围与各方动作

## 每次采集

先发现当前会话真实可用schema，按需调用已有行情/背景/公开池工具；没有工具不猜接口。当前未有广度、龙虎榜专门接口时，主动用可核的免费公开网页汇总补源，不能由“无接口”省略核查；有界检索仍失败就列缺口，不安装新引擎、不付费、不全市场逐股扫描。

从交易所、监管/政府、发行人、基金管理人及公开原始发布者取事实；跨至少两个独立发布者复盘核结构，无法取得时说明实际覆盖。证券时报/e公司同稿、财联社转载及门户镜像按原稿主体、发布时间、原文链接去重，转载数量不是证据强度。检索没有结果只表述“所查来源/期间未找到”，不能写“无利空/未入场”。

每条决定性事实保留 evidence_id、原始发布者/URL或公告编号、发布时间与精度、发生/统计区间、`known_at`及出处hash/档案引用。日期-only保留日期，不能补00:00来证明赶上盘前截止；当前取得时间只证明截至本次可访问，不能代替历史首次公开时间。更正保留旧版与更正链，截止后的修订另记版本。

来源状态至少区分 `available`、`unpublished`、`access_failed`、`unsupported`、`stale`、`missing`、`invalid`，按实际接口映射并写原因/检查时点。未发布与接口失败不是零，也不是中性。迟报两融、基金持仓、盘后榜单均写最新可得统计日，不能用当日新闻标题洗成当日资金动作。

市场数字附沪/深/北、股票/基金、主板/创业板/科创板、ST/新股/停牌剔除、涨跌停定义等实际口径。广度分母、涨跌幅中位数、尾部分位/跌幅分布有真实来源才报；只拿到涨跌家数就不能声称全套广度已覆盖。涨停家数、炸板分母、封板率、连板梯队和晋级率须同源同窗口，盘中与收盘分开，板块制度差异保留。量额核单位与统计窗；重叠指数不相加。

## 各方动作核查表

每次都列以下各方的已查范围、统计区间、来源状态、支持事实、限制和市场含义。支持与反证并列，不把相关性当买方身份或原因。

| 对象 | 可支持的证据与不可跨越的边界 |
| --- | --- |
| 国家队 | 按实名主体与具体动作核官方公告、本人声明或法定披露；ETF成交放大/份额变化、机构席位和媒体猜测不确认国家队买入。国家队结论按下表独立呈现。 |
| 政策部门 | 原文发布/生效日期、工具、适用对象、资金落实阶段；会议表态不等实际投放，传导路径和反向约束分开。 |
| 机构 | 管理人原文、定期持仓及可核研究观点分开；机构专用席位只是该席位披露，不映射具体基金或全部机构，不把存量持仓当当日买卖。 |
| 外资/北向 | 先核现行官方披露机制。当前北向不提供官方每日买入/卖出及净买入数据；日成交总额、额度余额、季度持股、南向买卖均不能替代北向日净流入。第三方估计只标估计及方法，不当官方事实。 |
| ETF | 二级成交额与一级申赎/份额、价格与净值区分；份额变化核日期与单位，不由成交量猜净申购/买方身份，也不把多只ETF重叠暴露相加。 |
| 两融 | 交易所余额与可得变动，明确T日/最新公开日；余额变化不等全部主动资金，不用缺报填零。 |
| 龙虎榜 | 单日榜与连续多交易日累计榜独立，核上榜原因、证券、日期、买卖总额与净额；不重复相加重叠区间，不从营业部推断完整账户、次日计划或永久持仓。 |
| 衍生品 | 中金所/交易所官方成交、持仓、基差等可得项；合约、到期与统计日对齐，会员席位不等最终客户，增仓不独自证明方向或对冲动机。 |
| 公司/股东 | 回购/增减持计划、已实施数量/金额、期限、解禁日与可流通规模、业绩/订单分别核原公告及更正；计划不等完成，解禁不等已减持，意向订单不等利润兑现。 |

### 国家队四态

| 状态 | 使用条件与表述 |
| --- | --- |
| `CONFIRMED_ACTION` | 可追溯直接证据确认实名主体、动作及时间范围；只确认该范围，不扩成全天/持续入场。 |
| `INDIRECT_EVIDENCE` | 只有可核的间接观察，明确不能确认买方身份及替代解释，不写“已入场”。 |
| `LAGGED_HOLDING` | 只有定期/滞后持股，写截至何时及公布时点，不能推断今天买卖。 |
| `INSUFFICIENT_EVIDENCE` | 未取得足够证据或来源未发布/失败；不能写“国家队未入场”。 |

同一报告可分别列不同时段/主体的证据，禁止把滞后持仓升级为今日动作。无可归因证据默认 `INSUFFICIENT_EVIDENCE`，不是负面事实。

现行北向口径的官方核查起点：[深交所2024-07-26通知](https://investor.szse.cn/szhk/hkbussiness/news/t20240726_608353.html)、[上交所机制说明](https://www.sse.com.cn/aboutus/mediacenter/hotandd/c/c_20240412_10753188.shtml)。2024-08-19起的日总额/季度持股口径须在每次报告核是否有后续调整，不将本参考当永不变的现行规则。
