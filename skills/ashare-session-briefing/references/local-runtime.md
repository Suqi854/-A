# 运行、归档与通知的通用接入边界

本包只提供分析流程，不包含调度器、行情服务器、账户数据库、通知适配器或自动发布实现。没有当前运行证据，不能声称后台继续、自动唤醒、可靠提醒或手机到达。

## 开始研究

使用当前获授权的运行环境，不猜模块、命令、目录或私有接口。核真实日期、Asia/Shanghai、模式、交易日历来源与覆盖。星期和调休工作日不等于交易日；日历未知、越界或来源验证失败时，依赖交易日的自动动作保持 UNKNOWN/HOLD。

运行窗口、报告期限、预测期限与归档目录由当前任务或已有获授权配置确定，本公开包不带个人时间表。凭据留原安全存储，不因接入需要读取或复制密钥。

## 报告与归档

按[报告合同](report-contract.md)生成内容，记录真实开始/完成时刻、证据截止、有效期、来源、规则版本、关联计划和实际覆盖。hash必须对真实保存的表示计算，不能编造。持仓逐只覆盖依据已授权、同版本账本核实；计数不能替代分析。

获准保存时使用当前指定目的地，追加报告身份、版本、前版引用与校验摘要，不覆盖旧判断。存在并发控制时使用其实际版本检查；没有实现时标明持久化、恢复与冲突处理未验证。

迟到稿保留真实完成时间与原截止，说明迟到范围。重新评估产生新版本，不能沿用旧版发送资格或回填为按时完成。

## 通知与隐私

仅在明确外发授权下，使用已验证渠道发送当前有效版本；普通分析和技能更新不会创建通知任务。最小摘要与完整报告分开，外部渠道不得夹带完整持仓、数量、成本、资产、公式、模型输入、私有参数或凭据。

发送前核当前证据、计划/报告版本、作用域、有效期、手动暂停、共享额度及内容白名单。过期或已撤销版本不得继续发送。请求返回、平台受理、渠道发送与本人本次实收分开记录；未知结果先查原事件，不能自动重复。

暂停未来调度与取消已开始任务分别核验；关闭应用、休眠、网络失败及宿主加载状态分别影响运行。没有实测就报告具体缺口，不将源码、合成测试或历史成功当作当前闭环证据。
