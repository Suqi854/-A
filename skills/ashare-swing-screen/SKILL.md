# 波段与行业候选

先给当前首选候选或“暂无可选”，说明关键依据、触发/失效和备选。优先可解释规则，再讨论模型；经营龙头、量价匹配、热点成员和适合买入分别评价，不混成一个分数。

先读共用[数据规范](../ashare-analysis/references/data-coverage.md)相关部分，按[筛选契约](references/screen-contract.md)确认实际接口和覆盖。已有固定筛选入口按实际schema使用；新的行业研究流程不改工具公式、参数或数据服务。

## 范围与使用顺序

- 用户已确认的目标池为本次明确的行业分类、板块及经营龙头候选范围，加独立私人自选；候选较少或无足够证据则少列/留空。分类版本、成员与经营依据有来源，不按涨幅/热门/市值单项凑数。
- 用已连接的 `a_get_stock_pool` 时核公开研究快照的实际分类、版本、范围、来源与质量；不把field-leader或hotspot标签自动认作全申万三级经营龙头池。
- 原公共主板目录只是身份范围，原固定筛选是当次已完成日线结果；两者都不能代替经营龙头证据。需要经营比较读[基本面研究](../ashare-fundamental-research/SKILL.md)。
- 私人自选与公开行业池分开保留，持仓不是自动入选证据；按已有授权取得名单，不杜撰本地读取接口。默认聚焦本次获授权的重点候选，不自动扩大扫描。
- 用户明确要求全行业或全冻结范围时，按实际接口容量分批覆盖并对账，不依赖逐只手工选择；接口/数据缺口单列，已有有效子集可继续分析。

规则先解释来源、数据时点、适用周期和失败条件，再运行一次固定筛选。正式结果与另行人工诊断分开；缺完整日线不改成不匹配，过热提示不取消匹配。范围、规则或截止改变另记代次。

输出最值得继续跟踪的候选及相对备选的事实差异；经营/PIT缺口不拦已支持的量价分析，但不得报完整基本面筛选。缺全范围财报与成员证据时明确未完成范围。不承诺主升浪、胜率或收益；实际仓位用[持仓做T](../ashare-position-t/SKILL.md)，历史有效性用[策略验证](../ashare-strategy-validation/SKILL.md)。
