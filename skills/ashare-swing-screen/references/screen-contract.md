# 当前筛选与池契约

## 数据入口

运行时发现 `a_get_stock_pool`、`a_get_swing_screen`、`a_get_mainboard_universe` 等实际schema。名称不代表当前成功，不虚构行业、评分、任意公式、历史截止、回测或云同步接口。不同范围与来源分开核对。

公开池是发布的研究快照，须保留实际返回的身份、分类/版本/hash、证据日期、范围和失败/unknown；缺字段不补造。当前公开池若仅有部分行业、field-leader或hotspot成员，只报告该覆盖，不能改称全申万三级。

## 行业目标与经营证据

行业分类、板块、候选数量及经营龙头定义按当前任务明确；证据不足不凑数。以本次有效分类及披露解释经营规模/份额、产品或客户地位、盈利现金质量、持续经营与风险；指标适配行业，先说明规则与来源再排序。市值第一、涨幅第一不自动等于经营龙头。主题标签另列。

排除ST名称的原固定模块继续保留；名称过滤不等风险警示状态认证。用户明确保留ST或其他范围时不静默套原模块。公开正式池、私人自选、持仓与策略匹配相互独立，交集可展示但不改变原身份。

全行业建设须有分类覆盖账本：行业总范围/已处理/证据不足/失败/待处理，各行业来源与实际候选数。不能用少量示例、当前热门板块或历史赢家冒充已完成；当前候选技能不宣称已生成全池。

## 固定日线兼容

已有固定筛选使用当前服务真实返回的规则身份、公式、默认参数与版本；不把个人自定义条件传给公共服务。当前未获取完整规则时仅作有限事实比较，不能声称已复现固定筛选。匹配、初起/延续与独立过热标记分别解释，不根据结果临时调整。

核来源、复权、最小有效样本、目标会话、完成证据及缺口；时间门槛推定的日历完成不等交易所最终值，也不能提升旧盘中缓存。容量与分页使用实际schema，不猜参数或将目录/池调用当筛选完成。

## 冻结与覆盖

冻结名单、证券身份、范围/分类、来源版本/hash（若有）、研究截止/预期已完成会话及规则版本。不同日期、规则或代次不拼接。

对主板目录继续分别对账：
- `provider_rows = eligible_mainboard_non_st + excluded_st_name + excluded_other_boards + unclassified + unsupported`
- `eligible_mainboard_non_st = match + not_match + insufficient_data + failed_without_result + pending`

只对实际具备该契约的结果使用字段；其它池使用其真实分类计数，不制造假字段。身份重复/缺项/池外/形状无效归无可信结果，不能用summary默认零替代。合法数据不足不计不匹配或整批失败。

失败、数据不足及待处理各自保留；用户要求继续/重试时遵守实际服务语义与已有范围，拒绝/限流暂停相关请求，不改源或凭据。只有失败与pending为零才称本次冻结名单全处理，仍单列不可判定；来源目录完成不证明交易所全量、历史成员或成交。
