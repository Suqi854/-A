# A量化 5.0 · 交易终端

一个可以在电脑和手机上使用的 A 股低频量化工具：实时监控、多因子 + 多策略分析、明确的交易计划、完整模拟盘、每天两次自动选股，以及根据实战结果自我迭代。

> 本工具用于个人学习与模拟研究。所有评分、信号和交易计划都是模型输出，不构成投资建议。

## 启动

| 操作 | 方法 |
|---|---|
| 启动 | 双击 `launch.cmd`。启动后会弹出一个最小化的黑色窗口，那就是服务，关掉它服务就停了；浏览器会自动打开 http://127.0.0.1:18950 |
| 停止 | 双击 `stop.cmd`，或者直接关掉那个黑色窗口 |
| 离线演示 | 双击 `demo.cmd`。用模拟行情跑在 18951 端口，数据单独存放，不影响正式数据 |
| 手机访问 | 手机和电脑连同一个 WiFi，打开「设置」页显示的地址（例如 `http://192.168.1.5:18950`），再点浏览器菜单里的「添加到主屏幕」 |

- 只用 Python 标准库，不需要 `pip install`。程序会先找 `D:\python\python\python.exe`，找不到再用系统里的 `py` 或 `python`。
- 第一次启动时，如果 Windows 防火墙弹窗询问，请勾选「专用网络」并允许，否则手机访问不了。
- 自动选股只在程序运行时才会执行。所以交易日要让电脑开着、程序也开着；之后可以考虑部署到云服务器。

## 八个页面（键盘 F1–F8 切换）

| 键 | 页面 | 内容 |
|---|---|---|
| F1 | 监控 MON | 6 大指数分时、市场温度（涨跌家数、涨跌停、成交额、主力净额、涨幅分布）、大盘多空状态、外围市场、自选股（每 3 秒刷新）、涨幅榜、主力净流入榜、实时动态 |
| F2 | 选股 PICK | 9:26 竞价选股和 14:45 尾盘选股的结果。每只入选股票都有评分、估计胜率、触发的策略、机会说明、风险提示、止损和两档止盈；另附候选前 30 只。也可以手动运行 |
| F3 | 个股 ANLY | K 线（可拖动、缩放，手机上双指操作；叠加止损止盈线），分时，综合评分和评级（买入／轻仓试错／观望／减仓／回避），交易计划，主力行为（吸筹、拉升、洗盘、派发、撤离），9 个因子的得分，策略信号，以及学习要点 |
| F4 | 模拟盘 SIM | 「我的模拟盘」手动下单（可记录当时的心态）；「AI 自动盘」自动跟随选股买卖。按 A 股规则执行：T+1、100 股一手、涨停买不进、跌停卖不出、收佣金和印花税。统计胜率、盈亏比、最大回撤，并按心态分组看盈亏 |
| F5 | 迭代 LEARN | 当前因子权重和每次调整的原因、因子 IC、各策略的实战胜率、概率模型的检验结果、选股成绩单 |
| F6 | 回测 BT | 对单只股票回测任意一个策略。逐日只用当时能看到的数据，次日开盘买入，按同一套止损止盈规则卖出 |
| F7 | 日志 LOG | 选股、成交、提醒和学习的全部记录 |
| F8 | 设置 SET | 选股时间和门槛、止损止盈参数、自选股、微信推送（PushPlus／Server酱） |

## 选股逻辑（宁缺毋滥）

1. 拉取沪深主板全市场快照（约 3000 只），剔除 ST、次新股、停牌股、已涨停股和成交太小的股票。
2. 粗筛出 150 只，逐只计算 9 个因子：动量、趋势、量能、资金、强度、波动、估值、位置、流动性；再检测 8 种策略：趋势突破、多头回踩、放量启动、超跌反弹、MACD 金叉、主力吸筹、尾盘强势、竞价抢筹。
3. 综合分 = 因子分 × 75% + 策略分 × 25%。入选必须同时满足：综合分 ≥ 72、至少有一个可靠的策略信号、盈亏比 ≥ 1.4、短线不过热。大盘处于震荡或空头时，门槛会自动提高，入选数量也会减少。
4. 没有符合条件的股票，就明确告诉你「今天观望」。

## 自我迭代怎么做

- 每次选股时，把前 150 只候选的因子值存下来作为样本。收盘后自动回填这些股票之后 1 日、3 日、5 日的真实涨跌。
- 每天 15:30 计算每个因子的 Rank IC，也就是看因子分高的股票后来是不是真的涨得多：有效的因子加权，失效的因子降权。每次调整幅度有限制，并设了上下限，防止过拟合。
- 统计每个策略的实战胜率，相应调整策略权重。
- 样本满 200 个后训练逻辑回归模型，用前 80% 的数据训练、后 20% 检验。检验通过才会启用，用来给出「3 日上涨概率」。
- **历史冷启动**：第一次运行时，系统会在历史 K 线上「回到过去」逐日计算因子，自动生成上万个样本。这样第一天就能开始学习，不用干等几周。
- 每次迭代都会留档，在 F5 页面可以看到权重怎么变的、为什么变。

## 数据来源

腾讯财经（实时报价、日 K、分时）和东方财富（全市场快照、主力资金），都是公开网页接口。数据缓存在 `data\aq5.sqlite3`。

## 目录

```
aq5\        后端（market 行情 / factors 因子 / strategies 策略 / analysis 分析 / picker 选股 /

web\        前端（交易终端风，电脑和手机自适应）
data\       数据库和设置（自动生成）
tests\      离线测试：python tests\test_core.py
```
